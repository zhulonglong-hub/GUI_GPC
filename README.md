# GPC Dataset Manager

> **版本**: v1.0  
> **适用数据集**: GeoPCDataset_V1.0  
> **目标**: 大体量遥感分割数据集的GUI管理工具

---

## 功能概览

### 核心功能 (已实现)

- ✅ **浏览与预览** - 查询和可视化数据集样本
- ✅ **新增样本** - 导入新图像和标注数据
- ✅ **删除样本** - 安全删除(备份到回收站)
- ✅ **编辑字段** - 修改样本的标注信息
- ✅ **统计分析** - 数据集概览和类别分布

### 技术特性

- 🚀 **大文件友好** - 流式处理2.7GB JSON,不全量加载
- 💾 **数据一致性** - 维护4组JSON文件的联动更新
- 🔒 **安全写入** - 备份+临时文件+原子替换策略
- 🧵 **异步处理** - 后台索引构建和图像加载,UI不阻塞
- 📝 **操作审计** - 所有写操作记录到日志文件

## 快速开始

### 1. 环境要求

- Python 3.8+
- 操作系统: Windows / Linux / macOS

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置数据集路径

编辑 `config.py`,修改数据集根目录:

```python
DATASET_ROOT = Path(r"D:\GeoPCDataset_V1.0")  # 改为你的数据集路径
```

### 4. 运行程序

```bash
python main.py
```

## 使用说明

### 浏览功能

1. 选择搜索维度 (task_id / image_id / name / phrase)
2. 输入搜索关键词
3. 点击搜索,左侧显示结果列表
4. 点击列表项,右侧显示图像和标注详情

### 新增功能

1. 点击"选择图像"按钮,选择图像文件
2. 填写类别名称、属性等信息
3. 输入多边形数据 (JSON格式) 或使用矩形框快速标注
4. 选择数据集划分 (train/val/test)
5. 点击"提交新增"

### 删除功能

1. 输入 task_id 或 image_id 搜索
2. 选择要删除的条目 (支持多选)
3. 可选:勾选"同时删除图像文件"
4. 点击"删除选中条目"并确认

### 编辑功能

1. 输入 task_id 加载记录
2. 修改需要变更的字段 (phrase / name / attributes)
3. 点击"保存修改"并确认

### 统计功能

- 自动显示各split的样本数量
- TOP-20类别分布图
- 最近20条操作记录
- 点击"刷新"更新统计信息

## 数据格式说明

### 多边形格式 (Polygons)

```json
[[[[x1, y1], [x2, y2], [x3, y3], [x4, y4]]]]
```

示例:
```json
[[[[10, 10], [100, 10], [100, 100], [10, 100]]]]
```

### 矩形框格式

```
x_min, y_min, x_max, y_max
```

示例: `10, 10, 100, 100`

## 注意事项

### 数据安全

- 所有删除操作会先备份到 `recycle/` 目录
- 写操作采用"备份→临时文件→原子替换"策略
- 操作日志记录到 `logs/operations.jsonl`

### 性能优化

- 程序启动时构建轻量级内存索引 (仅22MB)
- 完整记录(含Polygons)按需流式读取
- 大图像自动缩略图处理 (≤2048px)

### 已知限制

- 当前版本不支持多边形可视化编辑 (需v2.0)
- 批量编辑功能待实现 (需v2.0)
- 偏移量索引采用简化实现 (可优化性能)

## 故障排查

### 问题: 启动时提示"数据集结构不完整"

**解决**: 检查 `config.py` 中的 `DATASET_ROOT` 路径是否正确,确保包含 `annotations/` 和 `images/` 目录。

### 问题: 搜索结果为空

**解决**: 
1. 点击菜单"文件 → 刷新索引"重建索引
2. 检查搜索关键词是否正确
3. 确认数据集文件是否正常

### 问题: 图像无法显示

**解决**: 
1. 检查 `images/` 目录中是否存在对应的图像文件
2. 确认图像格式是否支持 (.jpg/.png/.tif)
3. 查看状态栏是否有错误提示

## 技术架构

### 设计原则

1. **数据层与UI层严格分离** - `core/` 模块无UI依赖
2. **流式处理大文件** - 避免全量加载2.7GB JSON
3. **异步不阻塞** - 使用QThread处理耗时操作
4. **安全写入** - 备份+原子替换机制
5. **可迭代架构** - 模块化设计,便于扩展

### 关键技术

- **PyQt6** - 跨平台GUI框架
- **matplotlib** - 图像和多边形渲染
- **ijson** - 大JSON流式解析
- **filelock** - 跨平台文件锁
- **scikit-image** - 多边形处理
